# 강의 복습 퀴즈

수강생용 객관식 복습 퀴즈(10문제)입니다. `index.html` 파일 하나로 동작합니다.

- 큰 글씨, 큰 버튼, 글자 크기 조절(가− / 가+) 지원
- 정답이면 칭찬 메시지와 축하 효과, 오답이면 정답과 해설 표시
- 마지막에 점수와 틀린 문제 다시 보기

## 문제 바꾸기
`index.html`에서 `const QUESTIONS = [` 부분의 문제(q), 보기(options), 정답 번호(answer), 해설(explain)만 고치면 됩니다.

## GitHub Pages로 배포하기
Settings → Pages → Branch에서 `main` / `/ (root)` 선택 → Save
