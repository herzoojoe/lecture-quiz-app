# 바이브 코딩 복습 퀴즈

바이브 코딩 강의 수강생용 복습 퀴즈입니다. `index.html` 파일 하나로 동작합니다.

- **난이도 선택**: 하 · 중 · 상 (난이도마다 10문제)
- **문제 유형 선택**: 객관식 · 단답형 · 섞어서
- 정답이면 칭찬 메시지와 축하 효과, 오답이면 정답과 해설 표시
- 단답형은 띄어쓰기·대소문자를 무시하고 채점, 힌트 보기 / 모르겠어요 버튼 제공
- 큰 글씨, 큰 버튼, 글자 크기 조절(가− / 가+) 지원
- 마지막에 점수와 틀린 문제 다시 보기

## 문제 바꾸기
`index.html`의 `const QUESTIONS = [` 부분을 고치면 됩니다.

- `level`: 난이도 ("하", "중", "상")
- `q`: 문제
- `options`: 객관식 보기 4개 — **첫 번째에 정답** (화면에서는 자동으로 섞임)
- `answers`: 단답형에서 정답으로 인정할 말들
- `explain`: 해설

## GitHub Pages로 배포하기
Settings → Pages → Branch에서 `main` / `/ (root)` 선택 → Save
